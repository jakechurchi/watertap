NAMING CONVENTION:

X mod trains => The number of trains that can have shutdown and startups.  
fixed RR => RO recovery is fixed at 92.5% for all 4 trains
fixed feed => RO train feed flowrate is fixed at 602 m3/hr 
full flex => All trains can be modular and variable in recovery and flowrate
var_flow => Both recovery and feed flowrate (the flow is a ref to the permeate flowrate, which is impacted by both) 

NOTES:
- The water target for all the tests was 12000 AF with the justification of 12000/12 months = 1000 per month + two months of full shutdowns 
- ** All solutions in this folder are the same because the baseline solution is optimal **
